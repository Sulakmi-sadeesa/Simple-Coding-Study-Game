# 🎮 Simple Coding Study Game

An interactive educational game where players learn programming through fun coding challenges and quizzes. Progress through different levels by solving questions and completing coding tasks — making learning **C** and **Python** more engaging and enjoyable.

## Features
- Interactive coding challenges and quizzes
- Level-based progression system
- Questions and tasks for C and Python
- Educational and fun learning experience
- Runs directly in the browser

## Tech
Vanilla HTML/CSS/JavaScript

## How to Play
- Start the game and choose a level
- Answer coding questions and complete tasks
- Progress through levels by solving challenges
- Learn C and Python along the way
